# Perumnas – Landing Page

Адаптивная одностраничная посадочная страница для жилого комплекса Perumnas.  
Разработана в рамках портфолио для демонстрации навыков вёрстки и фронтенд-разработки.

[Смотреть демо](https://ваш-username.github.io/название-репозитория/)  
[Репозиторий на GitHub](https://github.com/ваш-username/название-репозитория/)

---

## Описание

Лендинг представляет собой современный, минималистичный сайт для компании, занимающейся кластерным жильём. Включает в себя:

- Фиксированную навигацию с эффектом скрытия при скролле вниз и появлением при скролле вверх
- Мобильное меню с плавным выездом, оверлеем и кнопкой закрытия
- Поисковую строку в мобильном меню с валидацией и обратной связью (alert)
- Слайдер изображений на Swiper с автопрокруткой и адаптивным количеством слайдов
- Галерею с увеличением через Fancybox (клик по фото открывает полноэкранный просмотр)
- Анимированное появление блоков при скролле (Intersection Observer)
- FAQ-аккордеон с плавным раскрытием ответов
- Кнопку «Наверх» с плавной прокруткой
- Полную адаптивность под все типы устройств (desktop, планшеты, мобильные)
- Семантическую вёрстку и базовую доступность (ARIA-атрибуты)

## Технологии

| Технология | Назначение |
|------------|------------|
| HTML5 | Семантическая разметка, ARIA-атрибуты для доступности |
| CSS3 | Кастомные свойства (переменные), Flexbox, Grid, медиазапросы, ключевые кадры, @font-face для локальных шрифтов |
| JavaScript (ES6) | Чистый JS без фреймворков: работа с DOM, события, requestAnimationFrame, Intersection Observer |
| Swiper | Библиотека для слайдера с автопрокруткой и breakpoints |
| Fancybox | Библиотека для модальных галерей с возможностью просмотра изображений |
| Git & GitHub Pages | Система контроля версий и бесплатный хостинг для демо |
